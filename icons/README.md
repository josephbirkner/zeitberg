# Material Symbols

The symbols in `material-symbols.svg` are copied from Google's official
[`google/material-design-icons`](https://github.com/google/material-design-icons)
repository. They use the outlined 24-pixel Material Symbols variants and are
distributed under the Apache License 2.0 in `LICENSE`.

The local sprite keeps the application usable without a third-party font or
runtime network request.

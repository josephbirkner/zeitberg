# zeitberg workspace

This repository stores private zeitberg data. Keep it private unless every enabled component is intentionally public.

Before connecting it to zeitberg, edit `zeitberg.json`:

- replace `workspace_id` with a stable unique value, such as a UUID;
- choose the workspace `name` and IANA `timezone`;
- leave the declared paths unchanged unless you move their files at the same time.

The public application and workspace format are documented at <https://zeitberg.io>.

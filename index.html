PERSONAL OPERATIONS · STATIC BY DESIGN

Many plans.
One place you own.

planplural brings time, tasks, and the next parts of everyday life into one calm workspace. The application is static. Your private data and its complete history live in a Git repository of your choice.

  • No planplural backend
  • Git-native data

01 · PRINCIPLES

A personal system with an exit door.

OWN

Your repository

Choose where the workspace lives. Clone it, inspect it, back it up, or move it without asking planplural.

SEE

Readable documents

Versioned JSON and ordinary commits make your data understandable outside the interface that created it.

RUN

A browser, not a service

The public site delivers application files. Authenticated reads and writes go directly to your Git provider.

02 · OPEN A WORKSPACE

Bring a private GitHub repository.

Create a private repository, initialize it with the planplural workspace files, and use a fine-grained personal access token. Read-only access is enough to browse; saving needs Contents: Read & write.

  1. 1Create or choose a private repository.
  2. 2Add planplural.json and the component documents.
  3. 3Connect here; the repository remains the source of truth.

GITHUB · AVAILABLE NOW direct connection

zeitplural is a static application. It reads and writes versioned workspace files directly in a Git repository you choose; zeitplural.io has no data backend.

  • Static HTML5
  • Direct provider API
  • Versioned JSON

            Locator link
            
Contains the repository, branch, workspace identity, sub-app, and current view. The recipient authenticates independently.

          

          
        


        

          

            Capability link
            
Anyone holding this link receives the token's repository access. Treat it as a bearer credential.

            
Use a dedicated, expiring, least-privilege token for exactly this repository. zeitplural cannot mint or restrict a token for you.
